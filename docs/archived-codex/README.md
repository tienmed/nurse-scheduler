# Lưu Trữ Cấu Hình Codex Workspace (Archived Codex)

Thư mục này dùng để lưu trữ các tệp giữ chỗ (placeholder) và cấu hình từ extension `Knworks.codex-workspace` (`.codex`, `agents`, `skills`, `prompts`, `templates`) được chuyển khỏi thư mục gốc của dự án.

## 🎯 Mục Đích
- **Giải phóng ngữ cảnh Antigravity:** Tránh việc các tệp toml mẫu bằng tiếng Anh (`scheduler_assistant.toml`) và các thư mục rỗng làm loãng sự chú ý của Agent trong quá trình quét mã nguồn dự án.
- **Bảo toàn dữ liệu:** Giữ nguyên 100% cấu hình dự phòng để người dùng có thể kích hoạt lại bất kỳ lúc nào nếu cần dùng extension Codex trên VS Code.
